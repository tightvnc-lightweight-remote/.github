## Fast Remote Control Brief

What is TightVNC? A free, open-source remote control package for Windows.  
Why "Tight"? It uses Tight encoding to shrink data for slow links.  
Is it really free? Yes, it is distributed under the GNU GPL at no cost.  
Does it include a server? Yes, both server and viewer come in one install.  

## Remote Control Overview

TightVNC earned its name from the Tight encoding it pioneered, a compression scheme that dramatically reduces the amount of data sent for each screen update. On constrained connections this translates to noticeably smoother control than plain VNC delivers.

The software prizes simplicity and a tiny footprint. Its installer is small, its resource use is modest, and it runs happily on older hardware, making it a practical option for keeping aging machines useful and manageable from afar.

Being free and open source under the GPL, TightVNC has become a staple in schools, small businesses, and home labs where budgets are tight but reliable remote access is still essential for day-to-day support.

## Getting Started Playbook

Install TightVNC from the badge above and choose to set up both the server and viewer components. During configuration, define a connection password so only authorized users can reach the machine you are sharing.

On the controlling computer, launch the viewer, type the host's IP address, and enter the password to open a session. If a link is slow, keep Tight encoding enabled and lower the color depth to squeeze out extra responsiveness.
